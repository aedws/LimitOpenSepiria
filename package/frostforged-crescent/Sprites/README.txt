이 폴더의 PNG 가 무기에 적용됩니다. 없는 파일은 기본 카타나의 그림을 그대로 씁니다.

  icon.png          무기 아이콘 (목록·HUD)
  icon_big.png      큰 아이콘 (무기 선택 화면)
  weapon_right.png  캐릭터가 손에 드는 칼. 손잡이가 왼쪽, 칼끝이 오른쪽
  weapon_left.png   같은 그림의 좌우 반전
  weapon_up.png     손잡이가 아래, 칼끝이 위
  weapon_down.png   손잡이가 위, 칼끝이 아래

칼 그림은 게임의 원본 그림이 향하는 방향을 보고 네 장 중 하나가 자동으로 골라집니다.
weapon.png 라는 파일을 직접 넣으면 방향 판단 없이 그 그림이 쓰입니다.

직접 그릴 때
- 투명 배경 PNG. 해상도는 자유입니다(화면 크기는 원본에 맞춰집니다).
- 손잡이를 쥐는 위치(기준점)는 원본 그림에서의 비율을 그대로 따릅니다.
- 원본의 크기와 기준점은 게임을 한 번 실행한 뒤 Player.log 의
  "[FrostforgedCrescent] 아이콘 / 큰 아이콘 / 무기 그림" 줄에 나옵니다.

현재 들어 있는 그림은 이미지 생성 모델로 만든 뒤 픽셀 크기에 맞춰 줄인 것입니다.
