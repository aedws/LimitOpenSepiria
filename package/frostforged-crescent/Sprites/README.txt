이 폴더에 아래 이름의 PNG 를 넣으면 무기에 적용됩니다. 없는 파일은 기본 카타나의 그림을 그대로 씁니다.

  icon.png      무기 아이콘 (목록·HUD)
  icon_big.png  큰 아이콘 (무기 선택 화면)
  weapon.png    캐릭터가 손에 드는 칼 그림

그리는 기준
- 투명 배경 PNG, 픽셀 아트(확대·흐림 없이 1배 크기로).
- 원본과 같은 크기, 같은 방향으로 그리면 위치 조정 없이 맞습니다.
  원본의 크기와 기준점은 게임을 한 번 실행한 뒤 Player.log 의
  "[FrostforgedCrescent] 아이콘 / 큰 아이콘 / 무기 그림" 줄에 나옵니다.
- 손잡이를 쥐는 위치(기준점)는 원본 그림에서의 위치를 그대로 따릅니다.
